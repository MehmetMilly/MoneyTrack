## Longer Version

MoneyTrack is a personal finance app built with React, TypeScript, Vite, Zustand, Firebase Authentication, and Cloud Firestore. It helps users model money coming in, money going out, accounts, debts, installments, reminders, and savings goals. The project is still in active development, but it already includes authenticated routes, Firestore-backed user data, account and transaction flows, planning entries, goal progress, obligations, and SAR-focused formatting.

Personal finance tracking matters because small reliability and UX issues can make an app hard to trust. That makes MoneyTrack a strong practical project for improving my engineering habits: clear docs, careful data modeling, tests around calculations, honest security notes, and a cleaner user experience.

Codex would help me maintain and improve MoneyTrack by reviewing pull requests, adding tests for financial logic, refactoring state/data flows, improving Firebase error handling, documenting Firestore security assumptions, and catching UI regressions. Over the next six months I would focus on better tests, recurring obligation support, data export/import, dashboard clarity, mobile QA, and safer Firebase rules documentation.

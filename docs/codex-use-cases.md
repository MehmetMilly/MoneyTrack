# Codex Use Cases for MoneyTrack

MoneyTrack is a practical project for Codex because it has real app surfaces, user data flows, and financial logic that benefit from careful review.

Useful Codex tasks include:

- Refactor finance calculation utilities into smaller testable modules.
- Add tests for account balance updates, transfer reversals, planner totals, and goal progress.
- Improve Firebase auth and Firestore error messages.
- Add recurring payment and obligation logic.
- Improve dashboard charts and responsive layouts.
- Audit accessibility across forms, navigation, buttons, and empty states.
- Review pull requests for regressions in auth, data access, and financial calculations.
- Generate docs from current TypeScript types and repository code.
- Add safe import/export for user-owned data.
- Document and test Firestore security rules.

Six months of Codex or ChatGPT Pro would be useful here because the project has many small reliability tasks rather than one single rewrite. The best use would be steady iteration: write tests, fix edge cases, review UX, improve docs, and validate deployments.

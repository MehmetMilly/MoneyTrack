Create one high-resolution product concept board for a bilingual personal finance app called MoneyTrack.

Format:
- One single image, 16:9 landscape.
- Six screenshots in a 2x3 grid.
- Prioritize Android mobile views, with one desktop companion dashboard.
- Screens should look like usable app UI, not a marketing splash page.

Screens to include:
1. Mobile home dashboard in English: available money, goals, debts, installments, and upcoming reminders.
2. Mobile Arabic RTL dashboard.
3. Add transaction / obligation flow with large touch targets.
4. Goal detail screen with animated-feeling progress and contribution steps.
5. Installment/reminder timeline with swipe actions and paid/upcoming states.
6. Desktop web dashboard showing the same data synced across devices.

Visual direction:
Soft kinetic mobile-first. Design a warm, fluid, modern app that feels delightful but still serious about money. Palette: soft white, ink text, fresh green, coral alerts, sky blue accents, warm gray surfaces, and a few high-contrast black controls. Use rounded but controlled geometry, large tappable rows, bottom sheets, floating quick-add control, playful progress motion, and smooth state changes. It should feel friendly and habit-forming without becoming childish.

UX and content requirements:
- The app tracks assets/accounts, expenses, debts, installments, savings goals, and in-app reminders.
- Full EN/AR switching must be visible, including one full Arabic RTL screen.
- Currency is SAR.
- Show offline/sync confidence subtly.
- Make common mobile tasks fast: add item, mark paid, update goal, switch language.

Motion implication:
Show motion cues through overlapping mobile sheets, swipe states, springy progress rings, quick-add expansion, and list items mid-transition.

Avoid:
- Cartoonish finance, generic pastel dribbble cards, purple-blue AI gradients, random 3D coins, fake wallet illustrations, bloated empty space, stock charts, and text too small to read.
